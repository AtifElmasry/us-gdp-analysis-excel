# Publishing the completed workbook

1. Open the repository on GitHub and choose **Add file → Upload files**.
2. Drag in your completed `exploring-data-project(2).xlsx` file. GitHub's website normally uploads into the folder you are viewing.
3. Rename the file to `GDP_Analysis_Completed.xlsx` locally first if you prefer an easier filename.
4. If uploading from the repository root, place it there, then update the README's workbook location from `data/GDP_Analysis_Completed.xlsx` to the actual name.
5. Commit with message `Add completed GDP analysis workbook`.
6. Optionally upload screenshots of the GDP percentage table and pivot table to a `screenshots/` folder.
7. Check the workbook has the finished analysis, pivot table and final summary before sharing the repository.

This is a Codecademy-based learning project. Do not present the starter workbook or official solutions as original completed analysis.
